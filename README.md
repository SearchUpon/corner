# Corner（场角）

> 练习半年的拳馆学员，打完十拳，没人告诉他哪一拳没回位。Corner 把判据板钉在侧墙，让回合钟跟着他的视线：每拳半秒内判一次手位，一回合出一张能发给教练和自己的训练单。它不打分，也不替代教练。

**是什么**：面向拳馆学员的空间训练工具——真实沙袋 + 虚拟判据板，打沙袋时每拳半秒内给出手位判定，回合末生成一张可发给教练的训练单。

**不是什么**：不替代教练 · 不打分不排名 · 不做虚拟沙袋（真实沙袋 + 触觉反馈不可省）。

**技术栈**：PICO Spatial SDK（Kotlin + Compose，Shared Space 多窗口）。

**状态**：开发中 · PICO Space Program 2026 参赛作品 · 团队 SOTA Loop（索塔回环）
